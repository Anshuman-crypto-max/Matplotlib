# 📊 Matplotlib Crash Course

This repository contains my practice work completed while following the FreeCodeCamp Matplotlib Crash Course. The notebook demonstrates the fundamentals of data visualization using Python and Matplotlib.

- Line Plots
- Bar Charts
- Histograms
- Pie Charts
- Scatter Plots
- Plot Customization
  - Titles
  - Labels
  - Legends
  - Colors
  - Line Styles
- Figure Sizing
- Working with CSV Data
- Saving Figures
- Real-World Data Visualization

## 🛠️ Technologies Used

## ▶️ How to Run

1. Clone this repository:
   ```bash
   git clone <repository-url>
   ```

2. Install the required libraries:
   ```bash
   pip install matplotlib pandas numpy
   ```

3. Open the notebook:
   ```bash
   jupyter notebook
   ```

4. Run all cells to view the visualizations.
